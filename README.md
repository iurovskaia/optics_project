# optics_project
# Radio Field Scanner

Проект для автоматического двумерного сканирования электромагнитного поля в радиодиапазоне.

Установка перемещает измерительный зонд в плоскости XY и снимает карту поля в области примерно 25×25 см. Управление движением выполняет ESP32, а Python-программа на компьютере управляет экспериментом, получает данные с векторного анализатора цепей и строит тепловые карты поля.

Проект предназначен для исследования:
- распределения поля в ближней зоне;
- дифракции на щелях и отверстиях;
- интерференции волн;
- дифракционных решёток;
- численного пересчёта поля между плоскостями;
- сравнения экспериментальных и теоретических карт поля.

---

# Возможности проекта

- управление XY-сканером;
- движение по сетке точек;
- связь компьютера с ESP32 по Serial;
- управление шаговыми двигателями через драйверы TMC2209;
- измерение комплексного сигнала S21 с ВАЦ;
- сохранение данных в CSV / NumPy;
- построение двумерных тепловых карт;
- пересчёт поля на другое расстояние методом углового спектра;
- сравнение экспериментальных и расчётных карт.

# Как работает система

```text
Python-программа
    ↓
строит сетку точек XY
    ↓
отправляет команду MOVE на ESP32
    ↓
ESP32 двигает моторы
    ↓
ESP32 отвечает DONE
    ↓
Python ждёт стабилизации
    ↓
Python считывает S21 с ВАЦ
    ↓
сохраняет точку измерения
    ↓
строит карту поля
